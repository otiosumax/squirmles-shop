## Что это?
Это проект, созданный с целью повышения навыков быстрой разработки на react. Простой магазин-пустышка с основными функциями: каталог товаров, корзина, оформление и оплата заказа.

___

## Основная идея
**Основная идея** - минимальное использование библиотек для лучшего знакомства с ванильным react. Зачем использовать излишние инструменты, когда задача требует самых базовых?

## Стек
Использован ванильный TypeScript, React, CSS, React Router и.. всё.
- **React 19 + TypeScript** на **Vite**, без сторонних UI- и state-библиотек
- **React Router** — маршрутизация (`/` и `/checkout`)
- **CSS** — вложенные стили и CSS-переменные для темы
- Состояние — на `Context` + `localStorage`

## Возможности
- **Каталог** — товары подгружаются из `public/sample.json` и рендерятся карточками (`ItemCard`) с бейджем, рейтингом и ценой.
- **Корзина** — выезжающая панель: добавление/удаление, подсчёт количества и суммы. Хранится в `CartContext` и сохраняется в `localStorage`.
- **Оформление заказа** (`/checkout`) — форма с контактными данными, адресом доставки, способом доставки и платёжными данными.
- **Проверки формы** — обязательные поля, формат e-mail, индекс (6 цифр), номер карты (автоформат и алгоритм Луна), срок действия (не в прошлом), CVV.
- **Сводка заказа** — список товаров, стоимость и доставка, поле промокода.
- **Подтверждение заказа** — модалка об успешной оплате, после которой корзина очищается.

## Структура проекта
```
src/
├── components/   # UI-блоки: hero, collection, itemCard, cart, orderSummary,
│                 #           checkoutPopup, about, qna, footer
├── contexts/     # CartContext (корзина), ProductsContext (загрузка товаров)
├── models/       # типы предметной области (Product)
├── pages/        # страницы: shop, checkout
└── styles/       # глобальные стили и тема (CSS-переменные)
public/
├── sample.json   # данные о товарах
└── ...           # картинки и иконки
```

## Запуск
Требуются Node.js и npm.

```bash
npm install     # установить зависимости
npm run dev     # dev-сервер (Vite)
npm run build   # продакшн-сборка
npm run preview # предпросмотр собранной версии
npm run lint    # линтер
```
